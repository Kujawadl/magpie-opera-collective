{%- comment -%} Renders a responsive photo mosaic with a click-to-enlarge lightbox. Each photo needs two files already generated, following the naming convention `.jpg` (grid-quality, shown in the mosaic tile) and `-full.jpg` (lightbox-quality -- always the highest-resolution version available, shown when a tile is clicked). This include only renders markup for files that already exist; it does no image processing itself. Usage: {% include gallery.html folder="/assets/events/votre-toast/images/gallery" %} {% include gallery.html folder="/assets/events/votre-toast/images/gallery" max=12 more_link="/events/votre-toast/" more_text="See the Full Gallery" %} {% include gallery.html files="DSC00961,DSC00985,DSC01013" photo_dir="/assets/events/votre-toast/images/gallery" %} Params: folder - site-root-relative folder whose images (every `.jpg` that isn't itself a `-full` file) are all included, sorted by filename. Ignored if `files` is given. files - comma-separated string of basenames (no extension/suffix) to include, in the given order. Requires `photo_dir`. Takes priority over `folder` when both are given. photo_dir - folder the `files` list's images live in. max - optional. Caps how many images render. more_link - optional URL. Rendered as a link after the grid, but only when there are more images available than `max` actually showed. more_text - optional, default "See More Photos". alt_prefix - optional, default "Gallery photo". Prefix used to build each photo's alt text (" N of TOTAL"). Only one gallery (and its lightbox) is expected per page -- the lightbox markup and `.gallery-item` class are not namespaced per instance. {%- endcomment -%} {%- assign alt_prefix = include.alt_prefix | default: "Gallery photo" -%} {%- if include.files -%} {%- assign photo_dir = include.photo_dir -%} {%- assign photo_names = include.files | split: "," -%} {%- else -%} {%- assign photo_dir = include.folder -%} {%- assign photo_basenames = "" -%} {%- assign sep = "" -%} {%- for f in site.static_files -%} {%- if f.path contains photo_dir and f.extname == ".jpg" -%} {%- unless f.basename contains "-full" -%} {%- assign photo_basenames = photo_basenames | append: sep | append: f.basename -%} {%- assign sep = "," -%} {%- endunless -%} {%- endif -%} {%- endfor -%} {%- assign photo_names = photo_basenames | split: "," | sort -%} {%- endif -%} {%- assign total = photo_names.size -%} {%- assign max_count = include.max | default: total -%} {%- assign shown_names = photo_names | slice: 0, max_count -%} {%- assign shown_count = shown_names.size -%} {%- if shown_count > 0 -%}
